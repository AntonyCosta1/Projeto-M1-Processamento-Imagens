## Objetivo

Aplicar operações pontuais e técnicas de filtragem espacial em imagens
de melanoma do conjunto ISIC.

Foram comparados dois pipelines de processamento utilizando:

- ruído Gaussiano;
- correção gama;
- filtro Gaussiano;
- filtro da mediana;
- High-Boost;
- Laplaciano;
- métricas MSE e PSNR.
